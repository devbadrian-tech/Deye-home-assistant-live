# Deye Live

[English](README.md) | **繁體中文**

### 直接從逆變器，掌握家中的電力流向。

**Created by Adrian and Codex（由 Adrian 與 Codex 製作）**

Deye Live 是 Home Assistant 自訂整合，內附能源流向卡片。透過區域網路連接相容的 Deye 記錄器，顯示家居用電、電網輸入／輸出、電池功率、電池電量與太陽能發電。無須 Deye Cloud 帳戶或 Solarman V5 連線。

## 功能一覽

| 功能 | 說明 |
| --- | --- |
| 本地讀數 | 預設每 5 秒讀取逆變器數據 |
| 能源流向卡片 | 顯示電力流向、W／kW 功率與電池電量 |
| 電池限制 | 顯示充放電電流上限、低電量／關機／重啟門檻及排程目標 |
| 連線狀態 | 離線時清除目前讀數；數據過舊時標示延遲並暫停動畫 |
| 安裝方便 | 一個 HACS 整合包含感測器與卡片 |
| 配合儀表板 | 支援明暗主題、手機／平板版面、英文及繁體中文 |
| 無障礙支援 | 支援鍵盤操作與減少動態效果設定 |
| 唯讀操作 | 不提供逆變器控制、寫入服務、校時或韌體更新 |

### 可讀取的數據

| 類別 | 讀數 | 單位 |
| --- | --- | --- |
| 功率 | 家居負載、電網、電池、太陽能總功率、PV1、PV2、逆變器 | W；卡片按需要換算為 kW |
| 電池 | 電量百分比、電壓、電流 | %、V、A |
| 電網 | 頻率 | Hz |
| 電流限制 | 最大充電與放電電流 | A |
| 電池門檻 | 低電量、關機與重新啟動電量 | % |
| 排程 | 最低／最高目標感測器；快照／卡片提供六個時段 | % 與開始時間 |
| 快照 | 成功收到回應的時間及卡片使用的數據 | 時間戳記與屬性 |

功率感測器不是累計 kWh 電量表，無法直接當作 Home Assistant「能源」儀表板的累計電量來源。

## 相容性

**硬體實測：** Deye **SUN-5K-SG04LP1-AU** 搭配 **DYDA_WiBLE_1.7.2** 記錄器，使用標準 **Modbus TCP、連接埠 502、Unit 1**。

**Home Assistant 實測：** Core **2026.9.1**。本專案仍屬早期自訂版本，並非 Deye 或 Home Assistant 官方整合。

解碼器使用單相 **SG0xLP1** 暫存器配置。請勿套用於三相、高壓或使用不同暫存器配置的機型。同系列其他型號尚未逐一進行硬體驗證。

記錄器必須已提供本地 Modbus TCP 服務。部分 WiBLE 記錄器可透過 **Link2 → Modbus TCP** 啟用。本整合不會啟用或重新設定記錄器；原有雲端連線可繼續使用。

## 在記錄器啟用本地 Modbus TCP

以下適用於已實測的 WiBLE 記錄器韌體，其他型號的選單名稱可能不同。這是一次性的手動記錄器設定變更；整合本身只讀取數據。

1. 在路由器的已連接裝置清單找出記錄器目前的 IP。建議保留該 IP，避免之後變更。
2. 使用同一區域網路上的瀏覽器開啟 `http://<LOGGER_IP>/`，並以你自己的記錄器帳戶登入。請勿公開密碼或含登入資料的截圖。
3. 開啟記錄器的連結／連線設定，選擇 **Link2**。
4. 選擇 **Modbus TCP → Default**。**Link1** 保留原有 Deye Cloud 連線。除非記錄器文件另有要求，其他設定維持原值。
5. 套用／儲存設定。已實測的記錄器會提示套用後重新啟動，請等候它重新連上網路。
6. 在 Deye Live 輸入記錄器的區域網路 IP、**連接埠 502** 與 **Unit 1**。成功設定時會驗證逆變器身分並讀取即時功率暫存器。

Modbus TCP 並未加密，其他用戶端也可能透過它寫入設定。請只在可信任的區域網路啟用，**切勿將連接埠 502 轉發至網際網路**。

如果找不到 Link2 或 Modbus TCP，請查閱該記錄器型號／韌體的說明。Solarman V5 與透明傳輸的 Modbus TCP 是不同協定。

## 透過 HACS 安裝

1. 開啟 **HACS → ⋮ → Custom repositories（自訂儲存庫）**。
2. 加入 `https://github.com/devbadrian-tech/Deye-home-assistant-live`，類別選擇 **Integration（整合）**。
3. 在 HACS 找到 **Deye Live** 並下載。
4. 重新啟動 Home Assistant。
5. 開啟 **設定 → 裝置與服務 → 新增整合 → Deye Live**。
6. 輸入記錄器的本地 IP、TCP 連接埠及 Modbus Unit。先使用 **502**、**1**、**5 秒**。除非你的安裝使用相反的正負號慣例，否則請保持方向反轉選項關閉。

設定程序會先檢查逆變器系列、序號與功率暫存器，再接受連線。之後讀取時會驗證序號，避免 IP 變更後誤讀另一部裝置。

### 連線設定

完成安裝後，可在 **設定 → 裝置與服務 → Deye Live → 設定（Configure）** 修改。

| 設定 | 預設 | 用途／允許值 |
| --- | --- | --- |
| Host | 必填 | 記錄器的本地 IP 或主機名稱 |
| Port | `502` | TCP 服務連接埠；1–65535 |
| Unit | `1` | Modbus Unit；1–247 |
| 更新間隔 | `5` 秒 | 功率讀取間隔；5–60 秒 |
| 反轉電網方向 | 關閉 | 反轉顯示的輸入／輸出正負號 |
| 反轉電池方向 | 關閉 | 反轉顯示的充電／放電正負號 |

## 新增卡片

加入整合後，重新整理瀏覽器。編輯儀表板，選擇 **新增卡片 → Deye Live**，再選取逆變器的 **Live snapshot（即時快照）** 感測器。

視覺化編輯器可設定語言、標題，以及是否顯示太陽能與電池限制。**卡片語言（Card language）** 可選擇 **跟隨 Home Assistant**（預設）、**English** 或 **繁體中文**，每張卡片可獨立設定。

整合會自動提供並註冊卡片，通常無須另外下載 HACS 前端套件或手動新增儀表板資源。

```yaml
type: custom:deye-live-card
entity: sensor.deye_live_XXXX_live_snapshot
title: 家居能源
language: auto
show_solar: true
show_limits: true
```

請將 `XXXX` 換成 Home Assistant 實際顯示的實體 ID。若自訂前端阻止自動載入，可在儀表板資源新增 `/deye_live/deye-live-card.js?v=0.1.0&dashboard=1`，類別選 **JavaScript 模組**，再重新整理瀏覽器。

### 卡片設定

| YAML 欄位 | 預設 | 用途／選項 |
| --- | --- | --- |
| `type` | 必填 | `custom:deye-live-card` |
| `entity` | 必填 | Deye Live 即時快照感測器 |
| `title` | 依語言顯示標題 | 自訂標題會原樣保留 |
| `language` | `auto` | `auto` 跟隨 HA；`en` 英文；`zh-Hant` 繁體中文 |
| `show_solar` | `true` | 顯示／隱藏太陽能 |
| `show_limits` | `true` | 顯示／隱藏電池限制 |

自動模式跟隨正在查看卡片的使用者之 HA 語言；不支援的語言會改用英文。語言選項涵蓋卡片標籤、狀態、電池限制與編輯器。自訂 `title` 不會被翻譯；未設定 `language` 的舊卡片使用自動模式。

**語言選單已準備於下一版本提供；既有 0.1.0 發行版本尚未包含此選單。**

## 讀數說明

| 讀數 | 意義 |
| --- | --- |
| 家居 | 目前負載功率 |
| 電網 | 正數代表從電網取電；負數代表向電網送電 |
| 電池 | 正數代表放電；負數代表充電 |
| 太陽能 | PV1 與 PV2 的總功率 |
| 電池電量 | 逆變器回報的荷電狀態（SOC） |

方向反轉選項只改變讀數的解讀方式，不會改變逆變器運作。已在實測硬體觀察到電池放電；充電與電網輸入／輸出方向已有模擬測試，但尚未全部在硬體上實際驗證。

轉換損耗與量測時間差會使功率數值不完全平衡。感測器回報的是功率，不是累計電量。

### 電池限制是不同的設定值

| 顯示項目 | 意義 |
| --- | --- |
| 最大充電／放電電流 | 逆變器設定的電流上限，單位 A |
| 低電量 | 設定的低 SOC 門檻 |
| 關機 | 設定的關機 SOC |
| 重新啟動 | 設定的重新啟動 SOC |
| 排程目標 | 最低／最高 SOC 目標及六個排程時段 |

**排程 SOC 目標並非硬性的最高充電保護上限。** 電池 BMS 限制與其他運作設定可能另有約束。本版本不宣稱可讀取所有保護設定或 BMS 當下有效的電流允許值。以上設定均為唯讀顯示。

## 「即時」的意思

卡片使用每次成功收到本地回應的時間戳記，即使功率未變也會更新；不依賴感測器的 `last_changed`。

- 功率讀取失敗時，實體會標示為無法使用，並清除目前讀數。
- 若更新停止，經過三個讀取間隔（至少 15 秒）後，最後讀數會標示為延遲，並暫停流動動畫。
- 電池限制每分鐘讀取一次。選用限制欄位缺失不影響有效的功率讀數；卡片不使用超過 3 分鐘的限制數據。
- 缺失讀數顯示破折號，不會以虛構的零代替。

記錄器沒有提供逆變器的量測採集時間，因此「即時」代表剛收到本地回應，無法獨立量測記錄器內部的快取延遲。循序讀取暫存器也不代表所有數值在同一瞬間取得。

## 唯讀設計

整合的所有要求都使用 Modbus **功能碼 03 讀取**。傳輸層在連線前會拒絕寫入功能，並檢查交易 ID、Unit、功能碼、位元組數與回應長度。傳輸層也支援功能碼 04 的測試，但整合本身只使用 03。

本整合不註冊控制實體或寫入服務，不包含雲端登入、分析或遙測上傳。Modbus TCP 本身是未加密的本地協定，請只在可信任的區域網路使用，勿將連接埠 502 公開至網際網路。

## 疑難排解

| 狀況 | 檢查項目 |
| --- | --- |
| 無法連線 | 記錄器 IP、連接埠、Modbus 服務，以及 HA 到記錄器的網路連通性 |
| 裝置不支援 | 必須使用支援的 SG0xLP1 暫存器配置 |
| 找不到卡片 | 加入整合後重新整理瀏覽器；參考上方資源設定 |
| 電力方向相反 | 對照逆變器螢幕，並調整整合的對應方向反轉選項 |
| 電池限制顯示破折號 | 該欄位可能不支援、無效或暫時無法取得 |
| IP 位址變更 | 在路由器保留 IP，或修改整合的連線設定 |

若 0.1.0 重新整理後偶爾顯示 **Custom element doesn't exist: deye-live-card**，請將儀表板資源 URL 改為 `/deye_live/deye-live-card.js?v=0.1.0&dashboard=1`，類別使用 JavaScript 模組。

不同的 URL 會讓儀表板在前端準備完成後重新執行卡片模組，避免自動載入過早的問題，無須重新啟動 HA。這是針對 [Home Assistant 前端模組註冊時序問題](https://github.com/home-assistant/frontend/issues/53890) 的處理方式，不會改動遙測或逆變器設定。開發版本也會等候前端註冊表就緒後才定義卡片與編輯器。

回報問題時，請提供逆變器型號、記錄器韌體、HA 版本及錯誤訊息。公開任何內容前，請移除 IP、序號、登入資料與私人讀數。

## 開發與驗證

離線測試使用模擬數據，不會連接你的區域網路：

```sh
python3 -m unittest discover -s tests -v
```
